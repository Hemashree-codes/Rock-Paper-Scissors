# Rock Paper Scissors

A simple and interactive **Rock Paper Scissors** game built using HTML, CSS, and JavaScript.

Rock Paper Scissors is an interactive web-based game developed using HTML5, CSS3, and JavaScript. The project is designed to provide a simple, engaging, and user-friendly gaming experience while demonstrating fundamental front-end web development concepts. Players can choose between Rock, Paper, or Scissors, while the computer generates its choice randomly. The game then compares both choices and determines the winner based on the traditional Rock Paper Scissors rules.

The game includes a Best of 5 gameplay system where the player and computer compete across five rounds. A round counter keeps track of the current round, while separate score counters display the player's and computer's scores in real time. The application provides immediate feedback after every round, showing the selected choices and indicating whether the player won, lost, or drew.

To improve the overall user experience, the project includes several interactive features such as button hover effects, result animations, a final winner popup, confetti effects, and sound effects. When the five rounds are completed, the application automatically calculates the final score and displays the overall result. Users can restart the game at any time using the Reset or Play Again button.

The interface is designed using CSS with a responsive layout, allowing the game to work effectively on both desktop and mobile devices. JavaScript is used for game logic, random computer selection, score management, round tracking, DOM manipulation, animations, and sound generation through the Web Audio API.

This project helped strengthen practical knowledge of HTML structure, CSS styling, responsive web design, JavaScript functions, conditional statements, arrays, random number generation, event handling, DOM manipulation, and browser APIs. It also demonstrates how multiple front-end technologies can be combined to create an interactive browser-based application.

Overall, the Rock Paper Scissors project is a beginner-friendly front-end development project that demonstrates both programming logic and user interface design while providing an enjoyable interactive experience.

## Features

- Rock, Paper, and Scissors choices
- Random computer choice
- Best of 5 gameplay
- Round counter
- Player and computer score
- Win, lose, and draw messages
- Button and result animations
- Confetti celebration when the player wins
- Sound effects
- Final winner popup
- Reset / Play Again button
- Responsive design for mobile devices

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Web Audio API
